# module08_pytorch_mnist

In order to run this program, complete the following steps:

1. pip install -r requirements.txt   # if some of the included python packages are not pre-installed in your environment.
2. python run.py # defaults: 2 epochs, batch 1000, lr 0.001
3. python run.py -e 3 -b 500 -l 0.01 # to run with custom values
